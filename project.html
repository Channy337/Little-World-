Real Civorian decisions

Today the AI mostly re-ranks needs the rules already picked. Goal: flip that so people choose from what is in front of them, inside $25/month.

  • Call AI only at non-routine moments
  • Prompt caching (same rules/schema every call)
  • Batch API where delay is fine
  • Slow the clock only if needed (biggest cost lever)

Hunting (unbuilt)

Animals exist and are visible. There is still no hunt, trap, fish, or butcher path. Hunger only goes to farms, bushes, or market. Bone and hide stay unreachable until this is built.

Same design rule: discovery only. No hunt button. No forced behaviour.

Other remembered items

  • Shelter UI should feel in-world later; not a permanent big visitor panel.
  • Jarvis-style life profile remains an observation UI, not a control panel.

Rules Do not break

  • Public name is Civoria only. Repo and infra may still say little-world on purpose.
  • Never reset or reseed production to fix a bug or rescue a starving generation.
  • Never force planting, farming, or hunting. Fix senses and learning; discovery is theirs.
  • Browser is read-only observer. Server owns the truth.
  • No omniscient map or modern science in Civorian minds.
  • Preview branch + checks before production changes.
